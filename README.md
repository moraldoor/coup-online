# COUP ONLINE — Prototype 01

친구 초대형 레지스탕스 쿠 웹게임의 첫 번째 개발 단계입니다.

## 현재 구현된 기능
- 닉네임 입력
- 방 생성 및 5자리 초대 코드 발급
- 초대 코드로 방 참가
- 실시간 플레이어 목록 동기화
- 3~6명 인원 제한
- 준비/준비 취소
- 방장 권한 및 게임 시작 조건 확인
- 서버 연결 상태 오류 안내

> 아직 실제 쿠 게임(카드 배분, 코인, 액션, 도전, 방어)은 구현되지 않았습니다. 다음 단계에서 연결합니다.

## 준비물
- Node.js 20 이상 권장
- Visual Studio Code(권장)
- 터미널 사용

## 실행 방법

1. Node.js를 설치합니다: https://nodejs.org/
2. 이 폴더를 압축 해제합니다.
3. Visual Studio Code에서 `coup-online` 폴더를 엽니다.
4. 메뉴에서 터미널 → 새 터미널을 선택합니다.
5. 아래 명령어를 차례로 실행합니다.

```bash
npm install
npm run dev
```

6. 브라우저에서 http://localhost:5173 을 엽니다.

## 친구와 함께 테스트하려면
현재 버전은 내 컴퓨터에서 실행하는 개발용입니다. `localhost`는 내 컴퓨터에서만 접속할 수 있으므로, 친구와 원격으로 플레이하려면 다음 단계에서 서버를 인터넷에 배포하고 웹사이트도 배포해야 합니다.

## 문제 해결
- `npm`을 찾을 수 없다고 나오면 Node.js 설치 후 VS Code를 완전히 껐다 켜세요.
- 서버 연결 오류가 나오면 `npm run dev` 터미널에 오류가 있는지 확인하세요.
- 기본 주소는 프론트엔드 `http://localhost:5173`, 서버 `http://localhost:3001`입니다.
